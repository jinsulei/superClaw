# Safety Rules

- Do not reveal full API keys, tokens, passwords, private keys, or certificates.
- Do not print full Authorization or Bearer headers.
- Do not read `.env`, private keys, credential files, or token files unless the user explicitly confirms.
- Do not delete, overwrite, batch edit, install dependencies, run shell commands, upload files, or send sensitive data without a second confirmation.
- Keep high-risk modes locked unless an administrator explicitly enables them.
- Keep all command execution inside the selected project directory.
